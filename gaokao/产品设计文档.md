> 版本: v0.1 | 状态: 设计阶段 | 作者: AI 产品经理 + 认知科学专家组

---

## 一、核心理念

系统围绕三条经过认知科学严格验证的原则构建（源自 Dunlosky 2013 元分析、Carpenter 2022 Nature Reviews Psychology 综述）：

| 原则 | 科学依据 | 在本系统中的实现 |
|------|----------|------------------|
| **检索练习 (Retrieval Practice)** | 主动回忆比重新阅读记忆效果强 50%+；效果在长间隔后更显著 | 所有学习环节都要求你先回忆，再给答案 |
| **间隔重复 (Spaced Repetition)** | 分散在 1-3-7-14-30 天复习，比集中复习长期保持率高 2-3 倍 | SM-2 变体算法，自动调度每日复习 |
| **精加工编码 (Elaborative Encoding)** | 连接已有知识、问"为什么"、双重编码（文字+图像），促进深层理解 | 每个知识点支持：记忆线索、口诀、图示、为什么环节 |

引用核心文献：
- Dunlosky et al. (2013). *Improving Students' Learning With Effective Learning Techniques.* Psychological Science in the Public Interest.
- Carpenter, Pan & Butler (2022). *The science of effective learning with spacing and retrieval practice.* Nature Reviews Psychology.
- Karpicke & Blunt (2011). *Retrieval practice produces more learning than elaborative studying with concept mapping.* Science.

## 三、核心功能模块

### 3.1 双轨学习引擎

这是系统最核心的创新点——根据知识类型自动匹配最佳学习模式：

```
                    ┌─────────────────────────────┐
                    │       知识点录入              │
                    │   (选择分类 + 内容 + 记忆线索)  │
                    └──────────┬──────────────────┘
                               │
                    ┌──────────▼──────────────────┐
                    │        分类判断               │
                    │  (手动选择 / 系统建议)         │
                    └──────┬──────────────┬────────┘
                           │              │
              ┌────────────▼──┐     ┌─────▼────────────┐
              │   记忆轨       │     │    理解轨         │
              │ (Flashcard)    │     │ (深度加工)        │
              └───────┬───────┘     └──────┬───────────┘
                      │                    │
              ┌───────▼───────┐    ┌───────▼───────────┐
              │ 间隔重复      │    │ 变式检索            │
              │ 正反面翻转    │    │ 自我解释            │
              │ 记忆线索提示   │    │ 知识图谱连接        │
              │ 双重编码(图)   │    │ 费曼式输出检查      │
              └───────────────┘    └───────────────────┘
```

#### 记忆轨 (Memory Track) — 用于：
- **元素化合物**（化学）：Na/Al/Fe/Cl/S/N 及其化合物的性质、反应方程式、颜色现象
- **化学实验**：仪器名称、操作步骤、检验方法、尾气处理
- **语文古诗文**：原文、默写、名句
- **英语单词/短语**：拼写、搭配、用法
- **生物概念**：定义、分类、名词

**交互方式：** 卡片翻转（正面→尝试回忆→反面确认）→ "记住了" / "没记住" → 自动调度下次复习

#### 理解轨 (Understanding Track) — 用于：
- **反应原理**（化学）：速率平衡、电化学、离子平衡的原理推导
- **有机化学**：反应机理、推断逻辑、官能团转化
- **物理**：公式推导、模型理解
- **数学**：解题思路、定理证明

**交互方式：**
1. **变式检索**：同一个知识点从 3 个不同角度提问
2. **自我解释**：提示"请解释为什么这是对的"
3. **费曼输出**：让你用自己的话讲清楚→AI 评估有无漏洞
4. **概念连接**：自动推荐相关知识点，帮你建立网络

### 3.2 间隔重复算法

采用 SM-2 算法变体，跟踪每个知识点的 5 个参数：

```
{
  id: "unique_id",
  学科: "化学",
  分类: "元素化合物",        // 用于统计薄弱环节
  学习模式: "记忆轨",         // 记忆轨 / 理解轨
  正面: "Na₂O₂与H₂O反应",
  背面: "2Na₂O₂ + 2H₂O → 4NaOH + O₂↑",
  记忆线索: "过氧化钠遇水生氧+碱",
  
  // 间隔重复参数
  nextReview: "2026-05-25",   // 下次复习日期
  interval: 1,                 // 当前间隔（天）
  ease: 2.5,                   // 难度系数
  repetitions: 0,              // 成功回忆次数
  lapses: 0,                   // 遗忘次数
  lastScore: null,             // 最后一次评分 (0-5)
  
  // 理解轨额外参数
  variedQuestions: [
    "Na₂O₂属于哪类氧化物？",
    "Na₂O₂有什么实际用途？",
    "写出Na₂O₂与CO₂的反应方程式"
  ],
  selfExplanation: null,
  
  // 元数据
  createdAt: "2026-05-24",
  sourcePage: "必修一 P56"
}
```

**复习算法（简化版）：**

| 评分 | 含义 | 间隔调整 |
|------|------|----------|
| 5 | 完全记住，不假思索 | 间隔 × 2.0 |
| 4 | 正确，稍有犹豫 | 间隔 × 1.5 |
| 3 | 正确，但比较困难 | 间隔 × 1.0 |
| 2 | 错误，但记起后觉得简单 | 间隔重置为 1 天 |
| 1 | 完全忘记 | 间隔重置为 1 天，lapses++ |

### 3.4 知识点录入与管理

#### 3.4.1 单条录入
- 选择题：分类（记忆轨/理解轨）
- 填：正面 / 背面 / 可选记忆线索
- 理解轨额外填：3 个变式问题 / 自我解释

#### 3.4.2 批量导入（核心功能）
支持格式：
```
# 科目: 化学
# 分类: 元素化合物

Na₂O₂的特性 | 淡黄色固体，与水反应生成O₂，强氧化性 | 口诀：过氧钠遇水生氧
Na₂CO₃ vs NaHCO₃ | Na₂CO₃稳定，NaHCO₃受热分解 | 对比记忆：碳酸钠稳，碳酸氢钠热不稳
```

解析规则：
- `#` 开头为元数据（学科、分类、默认学习模式）
- 每一行：`正面 | 背面 | 可选：记忆线索`
- 一次性解析预览，确认后导入

#### 3.4.3 模板预置
系统为化学学科预置以下模板供选择导入：
- 元素化合物全套（Na → Al → Fe → Cu → Cl → S → N）
- 化学实验操作与现象
- 有机反应类型总表
- 常见记忆口诀

## 四、化学学科知识分类设计（首个试点）

基于高考大纲的完整分类：

```
化学/
├── 基本概念与理论 (混合型)
│   ├── 物质的量 (记忆+计算)
│   ├── 离子反应 (记忆+理解)
│   └── 氧化还原反应 (理解为主)
│
├── 元素化合物 (纯记忆)
│   ├── 钠及其化合物
│   ├── 铝及其化合物
│   ├── 铁及其化合物
│   ├── 铜及其化合物
│   ├── 氯及其化合物
│   ├── 硫及其化合物
│   ├── 氮及其化合物
│   └── 碳/硅及其化合物
│
├── 化学反应原理 (理解为主)
│   ├── 热化学与盖斯定律
│   ├── 化学反应速率与化学平衡
│   ├── 水溶液中的离子平衡
│   └── 电化学（原电池+电解池）
│
├── 有机化学基础 (理解为主)
│   ├── 官能团与命名
│   ├── 各类烃及其衍生物
│   ├── 有机反应类型（取代/加成/消去/氧化/还原/聚合）
│   └── 有机推断与合成
│
├── 物质结构与性质 (选考/理解)
│   ├── 原子结构与元素性质
│   ├── 分子结构与化学键
│   └── 晶体结构与性质
│
└── 化学实验 (纯记忆)
    ├── 常用仪器与基本操作
    ├── 物质分离提纯与检验
    ├── 气体实验室制备
    └── 实验方案设计与评价
```

**默认学习模式分配：**

| 分类 | 学习模式 | 理由 |
|------|----------|------|
| 元素化合物 | 记忆轨 ★ | 高考直接考性质、现象、方程式，必须精准回忆 |
| 化学实验 | 记忆轨 ★ | 仪器名称、操作步骤、检验方法都是固定答案 |
| 基本概念（定义类） | 记忆轨 | 术语定义需要精确 |
| 基本概念（计算类） | 理解轨 | 需要理解原理才能正确计算 |
| 反应原理 | 理解轨 ★ | 考的是逻辑推导和分析能力 |
| 有机化学 | 理解轨 ★ | 考的是推断和反应规律掌握 |
| 物质结构 | 理解轨 | 需要理解微观结构 |

> 用户可在录入时手动切换学习模式，系统建议只是起点。

## 五、基于学习科学的特色功能

### 5.1 记忆线索系统 (Elaborative Cues)
每条"纯记忆"知识点允许输入：
- **口诀**：如"浮熔游响红"（钠与水反应现象）
- **故事/联想**：把知识点编成小故事
- **图像描述**：用文字描述一张关联图像（未来可扩展为嵌入图片）
- **类比**：与已知知识建立类比

复习时，默认先不显示记忆线索 → 回忆成功后可选查看 → 加深编码。

### 5.2 变式检索 (Variable Retrieval)
对理解轨的知识点，复习时从 3 个不同角度提问：
- 角度 1：定义/概念本身
- 角度 2：与相似概念的区别
- 角度 3：应用场景

### 5.3 自我解释检查 (Self-Explanation)
理解轨复习完成后，提示用户：
> "用你自己的话解释一遍[知识点]。如果解释过程中卡住了，说明这里有漏洞。"

### 5.4 交错练习 (Interleaved Practice)
在不同分类之间交错安排复习，避免"学完一章忘前一章"。

### 5.5 双重编码支持 (Dual Coding)
预留图片嵌入接口——用户可以在知识点中添加关联图片 URL（如：实验装置图、反应机理图、周期表截图等），复习时文字+图像同时呈现。

## 六、潜在问题与自修复机制

| 潜在问题 | 自修复方案 |
|----------|------------|
| 录入内容太多，不想逐个输入 | 批量导入 + CSV/文本粘贴；预置模板一键导入 |
| 每天复习量过大 | 系统自动限制每日新卡数量（默认 ≤ 20 张新卡/天），优先复习到期的旧卡 |
| 用户不知道怎么分类"记忆"还是"理解" | 按学科/分类给出默认建议；用户可以随时切换 |
| 背了就忘，产生挫败感 | 系统设计"预期遗忘率"：前 3 次复习忘掉是正常的，不惩罚情绪 |
| 手机复习时不方便打字 | 评分按钮加大，操作以点击为主；支持手势滑动 |
| 不知道今天该复习什么 | 打开首页直接看到"今日待复习"队列，不用选择 |
| 某个板块持续掌握率低 | 系统自动标记薄弱板块，提示"建议集中突破" |
| 只有化学有内容，其他学科空白 | 模板通用化，每个学科有对应的默认分类模板 |
| 坚持度下降，最后几天放弃使用 | 界面极简化：每天打开→复习→关闭，全程不超过 10 分钟 |

## 七、技术约束与边界

- **纯静态 HTML + CSS + JS**，零后端依赖
- **数据存储**：localStorage（上限约 5MB，足够存 10000+ 卡片）
- **离线可用**：完全不需要联网
- **GitHub Pages 部署**：push 即上线
- **移动端**：CSS 响应式 + 触摸友好
- **数据备份**：支持导出 JSON 下载到本地
- **无第三方依赖**：一个 HTML 文件打天下
