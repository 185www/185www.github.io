# Gaokao Recall 系统改进方案

基于四路深度研究后的系统性重构方案。

---

## 一、双轨学习引擎重构

### Memory Track（记忆轨道）- 保留并优化
- 经典闪卡 + SM-2 间隔重复
- 适合：元素化合物、化学实验步骤、定义、公式、人名术语
- 优化点：SM-2 → FSRS-lite（增加 Retrievability 跟踪）

### Understanding Track（理解轨道）- 新增
三种模式，用户可自由切换：

**模式1：概念图重绘（Retrieval-based Concept Mapping）**
- 给一个核心概念（如"勒夏特列原理"），用户画出/写出与之关联的概念
- 系统对比标准概念图，计算覆盖度
- 科学依据：Carpenter 2022 - 从记忆中提取概念图比重新阅读效果好 2 倍

**模式2：变量检索（Variable Retrieval）**
- 给出部分条件，让用户推导缺失变量
- 例如：给出 ΔH > 0, 升高温度 → 用户推断平衡移动方向
- 训练条件-结果映射

**模式3：费曼解释（Self-Explanation/Feynman）**
- 要求用户用自己的话解释一个概念
- 可选"给高一学生讲"模式（检测真正理解）
- 系统给出关键点 checklist，用户自评覆盖

### 轨道选择指南
- Memory track: 元素符号、化学方程式、实验操作步骤、离子颜色、晶体类型
- Understanding track: 反应原理、化学平衡、电化学、物质结构、有机反应机理
- 混合: 元素化合物（记忆性质 + 理解规律）

## 二、间隔重复算法升级（SM-2 → FSRS-lite）

### 当前 SM-2 的局限
- 所有卡片同一初始间隔 → 没有区分卡片难度
- Quality 评分只有 4 级（1-4） → 区分度不够
- 没有 Retrievability 概念 → 无法预估当前记忆保留率
- 没有目标保留率设定 → 复习频率不可控

### FSRS-lite 设计

```
参数：
- D (Difficulty): 0-1，卡片的固有难度
  - 初始猜测：根据卡片类型预设（记忆型 0.3，理解型 0.7）
  - 每次复习更新：D' = D - w * (actual_rating - expected_rating)
- S (Stability): 以天为单位的记忆稳定性
  - 首次学习后：S(1) = 1 天
  - 复习后更新：S' = S * e^(rating_factor)
  - rating_factor 根据评分映射
- R (Retrievability): 当前记忆保留率，范围 0-1
  - R = 2^(-Δt / S)  （近似遗忘曲线）
  - 目标 R：建议 0.8-0.85（平衡效率与保留）
```

### 简化实现（不依赖 ML）
```
首次学习 → S = 1, D = 预设
复习成功 (rating 3-4):
  S' = S * (1.3 + 0.1 * (rating - 2))
  难度微调：D' = D - 0.05 * (rating - 3)
复习困难 (rating 2):
  S' = S * 0.3
  难度微调：D' = D + 0.1
复习失败 (rating 0-1):
  S' = 1
  难度微调：D' = D + 0.2

下次复习时间 = S' 天后（使 R 降到目标值）
```

### 迁移策略
- 现有卡片：保留已有复习记录，但添加 D=0.5 默认值
- 下次复习时自动按新算法计算

## 四、交互体验改进

### 4.1 渐进提示系统（Scaffolding）
```
遇到卡住时，点击"提示" →
第1级提示：给出类别提示（"这是一种过渡金属离子"）
第2级提示：给出部分答案（"它的颜色是___色"开头）
第3级提示：展示答案
```
科学依据：Bjork 2015 - 适当的难度提升记忆，但完全卡住会浪费学习时间

### 4.2 "全部输出"模式（Blurting）
- 给定一个主题（如"铁及其化合物"），用户在文本框中写出所有能记住的内容
- 完成后，系统用 checklist 扫描，标出遗漏点和错误
- 科学依据：Salmon 2020 - 自由回忆比定向回忆更能强化知识网络

### 4.3 交叉练习（Interleaved Practice）
- 复习时可选"混排模式"：随机混合不同类别、不同轨道的卡片
- 科学依据：Rohrer 2014 - 交叉练习使长期保留率提高 25%

### 4.4 知识点搜索
- 全局搜索框：跨所有化学类别搜索卡片
- 模糊匹配（支持中英文、缩写）
- 搜索结果直接跳转到对应卡片

### 4.5 键盘快捷键（桌面端效率）
- `Space`：翻卡/继续
- `1-4`：评分
- `h`：提示
- `s`：搜索
- `/`：搜索框焦点

## 六、数据层改进

### 6.1 存储结构

```javascript
{
  version: 2,  // 数据版本号，用于迁移
  categories: {
    "01-基本概念": {
      name: "基本概念",
      cards: [
        {
          id: "uuid",
          type: "memory" | "understanding",  // 轨道类型
          trackMode: "flashcard" | "conceptmap" | "variable" | "feynman",
          front: "问题",
          back: "答案",
          hints: ["提示1", "提示2"],
          textbook_ref: "必修1 P20",
          tags: ["氧化还原", "电子转移"],
          // FSRS 参数
          D: 0.5,     // difficulty 0-1
          S: 1,       // stability (days)
          R: 1.0,     // retrievability
          lastReview: null,  // timestamp
          nextReview: null,  // timestamp
          reviewCount: 0,
          lapses: 0,
          history: [
            { date: "2026-05-24", rating: 3, R: 0.95 }
          ]
        }
      ]
    }
  }
}
```

### 6.2 迁移支持
- `version` 字段
- 自动检测旧版本数据并迁移

## 七、工程架构改进

### 7.1 模块拆分
```
化学/
  shared/
    engine.js         ← 核心引擎（算法 + 数据层）
    category-page.js  ← 分类页面通用逻辑（太重了，需拆分）
    flashcard-view.js ← 闪卡视图渲染
    concept-map.js    ← 概念图组件
    blurting.js       ← 全部输出组件
    search.js         ← 全局搜索
    hints.js          ← 提示系统
    progress.js       ← 进度可视化
    styles.css        ← 样式

    理想情况下应该拆成多个文件。但考虑到离线 single-HTML 多页架构，
    建议用 dynamic script loading 或 build step。
    最简单的方案：保持单文件，但内部用模块 IIFE + namespace 拆分。
```

### 7.2 使用说明页面
- 首次使用时弹出引导（或常驻悬浮帮助按钮）
- 说明双轨模式区别与用法
- 间隔重复原理简释 → 用户信任算法，坚持使用
