# 📚 高考冲刺 · 记忆系统

离线可用的个性化高考复习系统，基于间隔重复 + 双轨学习引擎。

## 部署到 GitHub Pages

1. **创建仓库**
   - 在 GitHub 新建一个仓库，命名为 `gaokao`
   - 设为 Public

2. **上传文件**
   - 将本文件夹内的所有文件上传到仓库
   - 确保 `index.html` 在根目录

3. **开启 GitHub Pages**
   - 仓库 Settings → Pages
   - Source 选 `Deploy from branch`
   - Branch 选 `main`，目录选 `/ (root)`
   - Save

4. **访问**
   - 等待 2-3 分钟部署完成
   - 访问 `https://你的用户名.github.io/gaokao/`

## 使用说明

- 进入"化学"学科
- 首次使用点击"导入预设"一键导入所有化学知识点
- 每天打开执行"今日复习"即可
- 各分类可独立添加/导入自定义内容
- 全部数据存储在浏览器本地，离线可用
