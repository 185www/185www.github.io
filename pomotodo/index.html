      🍅 番茄钟

      ⏱️

      点击圆圈中的数字可以快速调整当前模式的时长（1-90 分钟）。

      专注 25 分钟 → 短休息 5 分钟 → 专注 → … → 每 4 个番茄后长休息 15 分钟。

      📱

      锁屏不中断：即使手机锁屏，计时器也会继续运行。重新打开页面会自动校准时间。

      建议开启浏览器通知，这样番茄完成时会收到提醒。

      🥔 土豆清单 (GTD)

      ✏️

      在输入框中添加任务，支持特殊语法：

      • #标签 — 分类标记，如 #写代码 #阅读
      • !1 !2 !3 !4 — 优先级（紧急/重要/一般/普通）
      • @today — 标记为今日任务

      示例：完成报告 #工作 !1 @today

      🔴🟠🟡⚪

      四级优先级：任务按紧急程度自动排序。

      🔴 P1 紧急 → 🟠 P2 重要 → 🟡 P3 一般 → ⚪ P4 普通

      点击任务上的优先级徽章可循环切换。

      ⌨️ 快捷键

      Space开始 / 暂停
      R重置计时器
      T切换到工作台
      S切换到设置
