# 新生 v5 — 完整产品重新设计

## 根本问题
v4 是"一个会说话的壳"。架构正确（PWA+微干预+紧急救援），但：
- 内容浅：对话是决策树模板，没有深度情景
- 无行动导向：光说"你试试"，没有具体行为任务
- 无个人化：所有用户得到相同对话
- 无音频：纯文本，不适合中老年用户
- 无社交：单机，没有家庭参与
- 无追踪：无法衡量实际行为变化

## 重新设计原则

1. **行动优先** — 每一次交互都以一个现实世界的行为任务结束
2. **文化深植** — 基于孝道、面子、命运、养生四大文化杠杆
3. **多模态** — 文本 + 语音 + 视觉 + 触觉
4. **社交嵌入** — 家庭守护人机制（一键求助 + 每日报告）
5. **极简UI** — 大字体、大按钮、少选项、多图片
6. **个人化** — 根据用户早期反应自适应调整策略

## 新干预协议架构

| 阶段 | 天数 | 目标 | 核心方法 |
|------|------|------|---------|
| P0: 动机接通 | 0 | 情感连接，建立信任 | 生命故事叙述，价值观映射 |
| P1: 习惯洞察 | 1-3 | 深层触发分析 | 3天行为追踪，触发画像 |
| P2: 替代构建 | 4-7 | 找到个人替代方案 | 尝试3+替代行为，评分优选 |
| P3: 挑战周 | 8-14 | 现实行为实验 | 每天一个具体挑战，"今天饭后散步10分钟" |
| P4: 身份巩固 | 15-21 | 身份转型 + 家庭庆祝 | 书写新故事，家人见证 |

## 交互模式变革

### 1. 行为日志（取代空谈）
不是"你感觉怎么样？"而是"今天抽烟了吗？/几次？/在什么场景？"
用大图标选择（☀️饭后 / 🏠在家 / 👥社交 / 😤情绪）

### 2. 每日挑战（取代对话）
每天给一个具体的、可做的任务：
- "今天饭后如果想来一根，先含一颗薄荷糖"
- "今天刷抖音之前，先站起来走一圈"
- "今天收到劝酒，练习说'我开车来的'"
用户只需回答：✓做到了 / ✗没做到 / 😅试了但没坚持住

### 3. 替代行为实验（取代建议）
- Day 1 替代尝试：口香糖（评分：没感觉 / 还行 / 有效！）
- Day 2 替代尝试：散步（评分）
- Day 3 替代尝试：喝茶（评分）
- 系统根据评分推荐最佳替代 + 调整后续内容

### 4. 家庭联结（取代单机）
- 守护人机制：用户选择一位家人接收每日进展
- 一键求助：点击→"我现在特别想抽烟" → 通知守护人
- 每日简讯："爸爸今天完成了第三天挑战！"

## 技术新增

1. **语音朗读 (TTS)** — 所有对话内容可选语音朗读，大喇叭按钮
2. **语音输入 (ASR)** — 可用语音代替打字/点击
3. **SVG 成长树** — 每完成一天，树长大一点，第21天开花
4. **守护人模拟** — 通过 Web Share API 分享到微信
5. **自适应引擎** — 基于前3天反应调整后续内容难度和风格

## 文化杠杆（中老年专属）

| 文化杠杆 | 应用方式 | 示例文案 |
|---------|---------|---------|
| 孝道 | 家人责任动机 | "你儿子/女儿可能从来不说，但他们每天都在担心你" |
| 面子 | 社会地位/尊严 | "能控制自己的人最有面子" |
| 命运 | 自主选择 vs 被控制 | "你是在选择，还是被习惯选择？" |
| 养生 | 传统健康观 | "元气是攒出来的，不是挥霍出来的" |
| 苦难哲学 | 老年人经历过的困难 | "你这一辈子吃了那么多苦，这点事难不倒你" |
