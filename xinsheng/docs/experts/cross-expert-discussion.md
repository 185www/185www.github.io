# 跨专家整合研讨：方案碰撞与融合

## 研讨背景

五位专家各自基于自己的专业领域提出了独立方案。本文件记录这些方案如何相互碰撞、冲突、融合，最终形成统一的整合方案。

---

## 第一轮：核心冲突与共识

### 冲突 1：直接呈现 vs 迂回策略

**行为设计专家**认为："入口必须完全不提及戒烟戒酒，伪装成一个'测试'。"

**数字健康干预专家**质疑："不提及戒烟戒酒，用户怎么知道这个工具是干嘛的？效果会打折扣。"

**认知心理学专家**调和："用户处在 Precontemplation 阶段时，直接提及=触发心理抗拒。但在 Contemplation 阶段后，直接效果更好。**产品应该有面：表层（任何人可用的计算器）和深层（逐步引导到改变话题）**。"

**共识**：
- 首页/主入口对所有人开放，标题中性（"身体年龄测试"）
- 仅在用户表现出参与意愿后（完成了第一次计算），才逐步展示改变导向的内容
- 核心原则：**Always let the user lead**

### 冲突 2：个人健康 vs 家庭情感

**中国文化专家**强调："在中国社会，家庭动力比个人健康更有效。产品应该以'家人'为核心叙事。"

**成瘾心理学专家**反驳："但是如果过度使用家庭情感，可能引发内疚感（Guilt），反而让用户逃避。自决理论指出，自主性才是持久改变的关键。"

**研讨结果**：
- 产品使用"家庭温暖"而非"家庭内疚"的基调
- 家人寄语是"鼓励"而非"控诉"
- 打卡成功后显示"你今天为家人多争取了一年的健康陪伴"（正向框架）
- 绝对避免"你对不起家人"之类的表述

### 冲突 3：内容广度 vs 深度

**认知心理学专家**指出："如果海量呈现内容，用户会产生认知过载。ELM 模型告诉我们，Precontemplation 阶段的用户只处理外围线索。"

**数字健康干预专家**指出："但同时，行为改变需要多触点。单一维度的干预效果有限。"

**共识**：
- **广度策略**：多维度触达（健康数据 → 科学真相 → 家庭情感 → 省钱计算）
- **深度策略**：单次只展示"一个"信息（一条科学卡片、一个目标建议）
- 产品遵循：**宽漏斗、浅触达** 原则

### 冲突 4：数据驱动 vs 尊重选择

**行为设计专家**提出利用助推机制："通过默认选项的设计，引导用户选择健康行为。"

**中国文化专家**担忧："对自主性高度敏感的中国中年人，被'设计'的感觉可能引发反效果。"

**成瘾心理学专家**引用动机访谈原则："任何让用户感觉到被操控的设计，都会破坏治疗联盟（Therapeutic Alliance）。"

**共识**：
- 助推设计透明化：用户知道自己在被引导，但保留完全选择权
- 例如：不预设"每天"打卡，而是"你有空的时候来看看"
- 核心原则：**透明引导，而非隐蔽操控**

## 第二轮：五大专家理论融合模型

经过研讨，五位专家联合提出了 **"新生"产品理论模型——5因素整合框架**：

```
┌─────────────────────────────────────────────────────┐
│                    "新生"模型                        │
├─────────────────────────────────────────────────────┤
│                                                      │
│  入口层：能力门槛极低（Fogg 行为模型）              │
│  ├─ 健康计算器（好奇心触发）                        │
│  └─ 不设限制、无需注册（自主性尊重）               │
│                                                      │
│  参与层：渐进承诺（Foot-in-the-Door）              │
│  ├─ 第一次打开：只是看看                            │
│  ├─ 第二次打开：试试打卡                            │
│  └─ 第三次打开：开始认真看科学内容                  │
│                                                      │
│  转变层：认知冲突 + 自我知觉（双重机制）          │
│  ├─ 认知失调：数据与信念的矛盾                      │
│  └─ 自我知觉："我在打卡→我是在乎健康的"           │
│                                                      │
│  维持层：习惯回路 + 社会支持                        │
│  ├─ 提示：家人提醒 / 每日卡片                       │
│  ├─ 回应：打卡 / 阅读                               │
│  └─ 奖励：身体恢复数据 / 省钱 / 家庭肯定             │
│                                                      │
│  文化层：中国化叙事                                 │
│  ├─ 以家庭为情感原点                                │
│  ├─ 以茶代酒等替代方案                              │
│  └─ 不使用"戒"字，使用"选择"叙事                  │
│                                                      │
└─────────────────────────────────────────────────────┘
```

## 第三轮：用户旅程的全流程设计

### 用户阶段映射（基于 TTM 跨理论模型）

```
Precontemplation → Contemplation → Preparation → Action → Maintenance
     ↓                  ↓              ↓           ↓           ↓
  健康计算器         科学卡片       设定目标      每日打卡    里程碑回顾
  好奇心内容        家庭寄语       制定计划      应对策略    分享经验给他人
  不要求承诺        金钱损失       替代行为      小小胜利    防止复发
```

### 详细用户旅程（以一个典型用户——你爸爸——为例）

#### 阶段 1：Precontemplation（前 Contemplation 阶段）
**场景**：儿子发来微信消息："爸，你帮我看看这个网页，算身体年龄的，好像挺准的"

**用户行为**：
1. 出于"帮儿子看"的目的，点击链接
2. 输入几个数字（年龄、每天吸烟量、每天饮酒量）
3. 看到结果："你的身体年龄比实际年龄大 8 岁"
4. 看到金钱数据："你已经在烟酒上花了 XX 万元"
5. 可能产生：轻微的吃惊（但不会立刻承认）

**产品触发**：
- 结果页加一句："想不想看看这些数字是怎么算出来的？→ 了解一下"
- 这是一个低承诺的下一步（只是"看看"）

#### 阶段 2：Contemplation（Contemplation 阶段）
**场景**：隔天，用户自己打开了页面（没有儿子提醒）

**用户行为**：
1. 重新看了一遍自己的数据
2. 点击了"科学真相"卡片
3. 看到第一条："每天喝二两白酒，一年等于吃 XX 块方糖的热量"
4. 看到第二条："酒精是一级致癌物，WHO 确认与7种癌症有关"
5. 心理活动：轻度认知失调（"我喝了几十年了..."→"但这是 WHO 说的..."）

**产品触发**：
- 在科学卡片末尾加一句温和引导："每天少喝一杯，身体会发生什么变化？→ 看看恢复时间线"
- 仍然不是"你必须改变"，而是"纯信息"

#### 阶段 3：Preparation（准备阶段）
**场景**：用户开始主动想"我是不是应该少喝点了"

**用户行为**：
1. 查看"身体恢复时间线"
2. 对某个数据产生兴趣（"戒烟20分钟心率就改善？"）
3. 看到"今天的目标"功能
4. 尝试设定一个微小目标："今晚少喝一杯"

**产品触发**：
- "试试今天的小目标？从最简单的开始"
- 预设目标不应超出用户舒适区太多
- 首次成功打卡后给予正面反馈（非夸张的庆祝，而是温暖肯定）

#### 阶段 4：Action（行动阶段）
**场景**：用户开始有规律地少喝/少抽

**用户行为**：
1. 每天打卡记录
2. 查看累计天数、省钱金额、身体恢复进度
3. 阅读每日一条科学卡片
4. 偶尔查看家人寄语

**产品触发**：
- 打卡后显示："你已经坚持了7天！你的肺功能正在改善"
- 里程碑提醒：3天、7天、14天、30天
- 每个里程碑都有不同的恢复数据

#### 阶段 5：Maintenance（维持阶段）
**场景**：用户已经形成新习惯

**关键挑战**：防止复发 + 应对复发

**产品触发**：
- 复发时："今天没坚持住？没关系，研究说平均需要6-7次尝试才能成功。重新开始就是！"
- "触发分析"："刚才是什么让你想抽烟/喝酒了？记录下来 👇"
- 长期维持策略：从戒烟戒酒转向更广泛的生活质量提升（运动、饮食）

## 第四轮：产品功能优先级矩阵

基于各专家的评估，对功能进行优先级排序：

| 优先级 | 功能 | 专家共识强度 | 开发难度 | 预期影响 |
|--------|------|-------------|----------|---------|
| P0 | 健康计算器（入口） | ★★★★★ | 低 | 极高 |
| P0 | 打卡系统 | ★★★★★ | 低 | 极高 |
| P1 | 身体恢复时间线 | ★★★★☆ | 低 | 高 |
| P1 | 省钱计数器 | ★★★★☆ | 低 | 高 |
| P1 | 每日科学卡片 | ★★★★☆ | 中 | 高 |
| P2 | 谣言粉碎机 | ★★★☆☆ | 中 | 中 |
| P2 | 家人寄语墙 | ★★★★★ | 低 | 高 |
| P3 | "如果我不在"模拟器 | ★★★☆☆ | 高 | 中 |
| P3 | 社交应对策略卡 | ★★★★☆ | 中 | 中 |
| P4 | 分享功能（炫耀里程碑） | ★★☆☆☆ | 中 | 低 |

**开发建议**：按 P0 → P1 → P2 顺序迭代，确保核心功能先行上线，后续根据用户反馈优化。

## 第五轮：争议问题最终裁决

### 5.1 该不该提供药物建议？

**成瘾心理学**：应提及医学帮助的存在，但不替代医生
**数字健康**：提供 NRT（尼古丁替代疗法）的一般信息，注明"建议咨询医生"
**最终决定**：在"资源"页提供一般性医学信息，带免责声明

### 5.2 能不能同时处理戒烟和戒酒？

**行为设计**：聚焦一个目标成功率更高
**中国文化**：但这两者在目标用户中高度关联
**最终决定**：主流程同时支持，但允许用户选择只关注其中一项

### 5.3 是否需要微信小程序版本？

**中国文化**：微信是最核心的触达渠道
**技术考量**：GitHub Pages 已可满足基本需求，微信小程序需要更多资源
**最终决定**：先做网页版，验证有效性后再考虑小程序化
