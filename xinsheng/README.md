# 新生 —— 抗成瘾数字化干预工具（戒烟·戒酒·戒短视频）

## 项目概述

「新生」是一个基于科学证据与心理学原理的静态网页工具，旨在帮助中老年人认识到吸烟、饮酒、短视频过度使用的危害，并通过正向引导逐步实现行为改变。产品采用 GitHub Pages 部署，零服务端依赖，纯前端实现。

**覆盖三种成瘾行为：**
- 🔴 **吸烟** — 主战场（Nature Human Behaviour 2025证据充分：RR 1.86）
- 🟡 **短视频过度使用** — 第二战场（APA Psych Bulletin 2025：98,299人Meta分析，无需安全警告）
- 🟢 **饮酒** — 可选附加模块（需AUDIT-C安全筛查，避免重度饮酒者危险戒断）

## 核心挑战

> **如何让一个坚信"喝酒养生"、抗拒改变的人，主动打开并使用这个产品？**

这是本产品最核心的设计难题。传统的"说教式"健康科普对处于"前 contemplation 阶段"（Precontemplation）的成瘾者几乎无效。本产品的设计哲学是：**不强迫、不说教、不评判**，而是通过精心设计的认知入口、动机访谈原则和数字助推（Digital Nudge），让用户自己发现矛盾、自己做出选择。

│   ├── 省下的钱/时间实时计数器

## 心理学理论基础（已整合）

| 理论 | 来源 | 产品应用 |
|------|------|----------|
| 动机访谈 (MI) | Miller & Rollnick, 2013 | 不评判的对话式引导 |
| 跨理论模型 (TTM) | Prochaska & DiClemente, 1983 | 根据用户所处阶段匹配内容 |
| 认知失调理论 | Festinger, 1957 | 通过数据创造轻度认知冲突 |
| 自我知觉理论 | Bem, 1972 | 小行为→态度改变（打卡改变自我认知） |
| 习惯回路 | Duhigg, 2012; Clear, 2018 | 用新习惯替换旧习惯 |
| 福格行为模型 | Fogg, 2009 | B=MAP（动机×能力×触发） |
| 助推理论 | Thaler & Sunstein, 2008 | 设计选择架构，引导健康决策 |
| 损失厌恶 | Kahneman & Tversky, 1979 | 强调"你正在失去什么"而非"你能得到什么" |
| 自我决定理论 | Deci & Ryan, 2000 | 自主性、胜任感、关系性三大基本需求 |
| 社会认知理论 | Bandura, 1986 | 观察学习、自我效能感 |
